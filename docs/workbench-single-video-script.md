# 单条视频正式脚本

## 视频定位

| 项目 | 内容 |
|---|---|
| 平台 | 小红书、抖音同发 |
| 时长 | 60 秒左右 |
| 形式 | 纯字幕录屏优先 |
| 受众 | 想用 AI 但又怕太复杂的普通人，外加毕业季求职者 |
| 主线 | 我不是想炫技术，我只是想把找工作里最烦的一步，用 AI 讲简单、做简单 |

## 逐秒脚本

| 时间 | 画面 | 字幕 / 口播 |
|---|---|---|
| 0-4 秒 | 招聘官网岗位列表快速下拉 | AI 不是只能写点高深东西。 |
| 4-8 秒 | 继续快速滚动，制造信息过载感 | 它也可以帮你解决这种很烦的小事。 |
| 8-14 秒 | 切到最终手册首页 | 比如找工作时，岗位太多太散，我就把它整理成了一份投递手册。 |
| 14-22 秒 | 展示岗位卡片、分数、城市、优先级 | 你给它招聘链接和简历，它会帮你排出更值得先投的岗位。 |
| 22-30 秒 | 展示更高分岗位和局部细节 | 所以你看到的不是一堆链接，而是今天先投什么。 |
| 30-38 秒 | 展示流程图 | 整个过程其实很简单，抓岗位，做匹配，出结果。 |
| 38-48 秒 | 展示配置文件局部和运行命令 | 我以后就会用这种最简单的方式，继续讲 AI 到底能帮普通人做什么。 |
| 48-56 秒 | 回到结果页，多停留 1 到 2 秒 | 不讲黑话，不装懂，就讲你能不能马上用。 |
| 56-60 秒 | GitHub 仓库和公开示例页 | 如果你想看这种宝宝也能懂的 AI 内容，就先关注我。 |

## 封面文案

| 类型 | 文案 |
|---|---|
| 主封面 | 宝宝也能看懂的 AI 找工作 |
| 备选 1 | 我用 AI 把找工作讲简单了 |
| 备选 2 | AI 也能帮你少翻很多岗位 |

|---|---|
