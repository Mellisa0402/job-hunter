# 宝宝AI 高级科技风格与脱敏规则

## 总方向

这条视频不是教程，也不是 PPT。

它是一条 60 秒左右的产品感短片，用 `job-hunter` 做例子，展示宝宝AI的核心理念：

> AI 可以把普通人的麻烦事做简单。

## 隐私规则

| 不能出现 | 替代方式 |
|---|---|
| 真实姓名 | `候选人`、`简历已脱敏` |
| 真实学校 | `学校信息已隐藏` |
| 真实公司投递目标 | `目标公司`、`招聘官网` |
| 具体隐私岗位 | `岗位 01`、`岗位 02`、`岗位 03` |
| 真实简历内容 | 只显示 `技能标签`、`城市偏好`、`经验阶段` |
| 真实链接参数 | 只显示 `careers.example.com/jobs` |

## 视觉规则

| 项目 | 定法 |
|---|---|
| 风格 | Apple 式高级简约科技感 |
| 背景 | 深黑、雾面灰、少量冷白光 |
| 字体 | 大字、少字、留白多 |
| 颜色 | 黑、白、银灰、极少量蓝绿高光 |
| 动效 | 缩放、推进、聚焦、扫描、轻微漂浮 |
| 禁止 | 大面积渐变、花哨霓虹、PPT 卡片堆叠、满屏代码 |

## 视频叙事

| 时间 | 讲什么 |
|---|---|
| 0-6 秒 | AI 不是只能写高深东西 |
| 6-14 秒 | 找工作的问题是岗位太散 |
| 14-28 秒 | 工具把岗位整理成投递手册 |
| 28-42 秒 | 分数、城市、优先级变清楚 |
| 42-52 秒 | 三步流程，抓岗位、做匹配、出手册 |
| 52-60 秒 | 回到宝宝AI定位，普通人也能用 |

## 文案原则

| 原则 | 说明 |
|---|---|
| 少字 | 每屏只放一句 |
| 先结果 | 先看清楚变化，再解释怎么做 |
| 讲人话 | 不出现 crawler、matcher、pipeline |
| 有高级感 | 语气冷静，不卖惨，不喊口号 |
| 有记忆点 | 结尾一定落到“宝宝AI” |
