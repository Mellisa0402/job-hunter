# 视频项目模板

## 这个文件夹是干什么的

这是一个单独视频项目的工作文件夹。

以后你每做一个新视频项目，都复制这一整个文件夹，再改成自己的项目名。

## 开始前只做三件事

| 步骤 | 你要写什么 |
|---|---|
| 第一步 | 这条视频讲什么 |
| 第二步 | 这条视频讲给谁听 |
| 第三步 | 这条视频想让别人看完做什么 |

## 最先填写

打开 `01_项目说明/项目简介.md`，把这三个问题写清楚：

1. 这条视频一句话讲什么  
2. 目标用户是谁  
3. 这条视频最后想让用户点赞、收藏、关注，还是点开链接  

## 目录说明

| 目录 | 用途 |
|---|---|
| `01_项目说明` | 项目定位和一句话简介 |
| `02_原始素材` | 录屏、截图、参考资料 |
| `03_脚本与标题` | 脚本、标题、封面文案 |
| `04_项目演示素材` | 项目结果和展示素材 |
| `05_封面与截图` | 封面图和平台截图 |
| `06_发布文案` | 平台文案和评论区引导 |
| `07_导出成片` | 最终视频 |
| `08_发布清单` | 发布前检查 |
| `09_复盘` | 数据复盘和下次优化 |
