# 展示包装首版

这份文档只管“别人第一次看到这个项目时会看到什么”。

## 现在已经有的

- 一条能跑通的抓取 → 匹配 → 出手册流程
- 一份更适合展示的投递手册样式
- 可公开的示例配置和基础说明

## 接下来要补的

- 一张首页展示图：让人一眼知道产出长什么样
- 一组流程图：说明输入、处理、输出
- 一段 30 秒演示文案：适合发仓库、发朋友圈、发群里
- 一份匿名样例数据：避免真实信息出现在公开仓库

## 展示结构建议

1. 封面一句话：从岗位列表到投递手册，一条命令跑完。
2. 三步流程图：抓取、匹配、生成。
3. 成品预览：展示手册首页和岗位卡片区。
4. 使用方式：只保留最短启动方法。
5. 适合谁用：校招、社招、跨城求职。
