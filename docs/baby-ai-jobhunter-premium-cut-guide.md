# `job-hunter` 高级产品片剪辑方案

## 核心变化

这版不再主用旧手册截图。

主画面改为 `宝宝AI_jobhunter_高级竖屏样片.html`，它已经做了：

| 项目 | 处理 |
|---|---|
| 姓名 | 全部隐藏 |
| 学校 | 不展示 |
| 真实岗位 | 改成 `岗位 01 / 岗位 02 / 岗位 03` |
| 真实简历 | 只展示脱敏标签 |
| 真实链接 | 改成示意链接 |
| 画面风格 | Apple 式高级简约科技感 |

## 录制方式

| 步骤 | 动作 |
|---|---|
| 1 | 打开 `宝宝AI_jobhunter_高级竖屏样片.html` |
| 2 | 浏览器窗口调成竖屏比例 |
| 3 | 用 OBS 或剪映录屏录 60 秒 |
| 4 | 导入 `视频字幕.srt` |
| 5 | 导出成片到 `07_导出成片` |

## 剪辑原则

| 项目 | 要求 |
|---|---|
| 主画面 | 只用新样片，不用旧手册当主视觉 |
| 字幕 | 少字、大字、留白 |
| 音乐 | 低频、克制、科技感 |
| 配音 | 可不要，先用字幕和音乐做第一版 |
| 节奏 | 像产品发布，不像教程 |

## 第一版字幕

| 时间 | 字幕 |
|---|---|
| 0-6 秒 | AI 不是只能写点高深东西。 |
| 6-14 秒 | 它也可以先解决一件很烦的小事。 |
| 14-24 秒 | 比如找工作时，岗位太多太散。 |
| 24-34 秒 | 我把它整理成了一份投递手册。 |
| 34-44 秒 | 先投什么，保留什么，一眼看清。 |
| 44-52 秒 | 抓岗位，做匹配，出手册。 |
| 52-60 秒 | 宝宝AI，把 AI 讲到普通人也能用。 |

## 不能出现

| 内容 | 原因 |
|---|---|
| 真实姓名 | 隐私 |
| 真实学校 | 隐私 |
| 真实岗位名称 | 可能暴露求职方向 |
| 大段代码 | 降低高级感 |
| 旧手册整页截图 | 信息太杂，不够像产品片 |
