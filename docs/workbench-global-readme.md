# 宝宝AI 视频总工作台

## 这个工作台怎么用

这个工作台不是只给一个项目用的。

它是你以后所有视频项目共用的一套总工作台。

## 你以后做新项目时

| 步骤 | 动作 |
|---|---|
| 1 | 进入 `00_项目模板` |
| 2 | 复制一份出来 |
| 3 | 改名成 `项目_项目名` |
| 4 | 放进 `10_视频项目` |
| 5 | 开始填项目说明、脚本、素材和文案 |

## 两条死规矩

| 规则 | 说明 |
|---|---|
| 公共东西不放项目里 | 比如账号定位、通用模板、统一文案 |
| 项目内容不放全局里 | 比如某个项目自己的素材、脚本、成片 |

## 最终目标

以后任何新视频项目，都不重新搭目录，只复制模板。
