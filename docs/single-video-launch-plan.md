# 单条视频发布方案

这份文档只做一件事，把 `job-hunter` 从 0 推到第一条正式发布视频。

## 现在的判断

| 项目 | 现状 | 结论 |
|---|---|---|
| GitHub 仓库 | 已公开，地址有效 | 可以直接作为视频落点 |
| 抖音账号 | 0 作品，0 粉丝，当前名字是「送你一匹千里马」 | 适合直接重做统一形象 |
| 小红书账号 | 已有账号，但本轮还没完成主页细看 | 不影响先发第一条 |
| 受众 | 毕业季求职者 | 必须先讲痛点，不先讲技术 |

## 对标结论

| 观察 | 结论 |
|---|---|
| 能传播开的开源项目视频，第一屏都不是代码 | 必须先放结果页 |
| 用户更关心自己能少花多少时间 | 不能把重心放在「这是个开源项目」 |
| 最容易让人停留的表达 | 不是岗位少，是信息太散 |
| 最容易让人收藏的内容 | 给出一个清楚的解决路径，而不是只展示厉害 |

## 第一条视频定位

| 项目 | 方案 |
|---|---|
| 视频目标 | 让毕业季求职者立刻明白这个工具能帮他少翻很多岗位 |
| 平台 | 小红书、抖音同发 |
| 形式 | 纯字幕录屏优先，必要时加温柔有活力的女声旁白 |
| 时长 | 55 秒到 75 秒 |
| 核心主线 | 找工作最烦的不是没岗位，是岗位太多太散，所以我做了一个把招聘官网岗位整理成投递手册的开源工具 |
| 这条视频不讲什么 | 不讲技术架构，不讲代码细节，不讲多平台规划 |

## 单条视频脚本

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0-5 秒 | 招聘官网长列表快速滚动 | 找工作最烦的，不是没岗位，是岗位太多，信息太散。 |
| 5-10 秒 | 切成手册结果页首页 | 所以我做了一个工具，直接把招聘官网岗位整理成一份投递手册。 |
| 10-18 秒 | 展示岗位分数、城市、优先级 | 它会先抓岗位，再按你的简历和目标城市做匹配排序。 |
| 18-28 秒 | 展示结果页里不同岗位卡片 | 最后你看到的不是一堆链接，而是今天该先投什么。 |
| 28-38 秒 | 展示流程图 `assets/flow-map.svg` | 整个过程很简单，抓岗位，做匹配，出手册。 |
| 38-50 秒 | 展示 `config/user.example.yaml` 和运行命令 | 你只要填自己的简历和求职方向，再给它一个招聘官网链接，就能直接跑。 |
| 50-62 秒 | 切回最终结果页和 GitHub 仓库 | 这东西我已经开源了，如果你最近正好在找工作，可以直接拿去试。 |
| 62-75 秒 | 仓库地址和公开示例页 | GitHub 和公开示例我放简介，有需要我再发完整教程。 |

## 声音方案

| 方案 | 结论 |
|---|---|
| 纯字幕录屏 | 最稳，最快，最不容易翻车 |
| 真人女声配音 | 效果最好，但需要找到稳定音源或真人配音 |
| 常见 AI 配音 | 容易有 AI 感，不适合你这条第一视频 |

| 当前建议 | 原因 |
|---|---|
| 第一条先用纯字幕录屏 | 先验证内容方向，别把时间耗在声音调教上 |
| 第二条开始再上配音 | 等账号风格跑顺后，再补声音识别度 |
