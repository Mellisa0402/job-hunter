# 演示文案

## 一句话版本

把招聘官网的岗位列表，变成一份能直接投递的手册。

## 30 秒版本

这是一个把招聘官网岗位自动整理成投递手册的开源项目。

你给它一个招聘页和一份简历，它会先抓岗位，再做匹配，最后给出一份更像行动清单的结果。

所以你拿到的不是一堆链接，而是我下一步最该投什么。

## 60 秒版本

很多招聘网站的问题不是岗位少，而是信息太散。

这个项目做的事很直接，先把岗位抓下来，再按简历、城市和方向做排序，最后输出一份可读性更高的 HTML 或 PDF 手册。

这样你不用手动翻很多页，也不用自己再整理优先级。

它更像一个求职决策工具，而不只是抓取工具。
