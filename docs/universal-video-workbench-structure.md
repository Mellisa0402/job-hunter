# 宝宝AI 视频总工作台结构

## 总原则

一个总工作台，下面放很多项目。

公共资源放一起，每个视频项目单独放一套自己的素材、脚本、成片和复盘。

## 建议结构

| 路径 | 用途 |
|---|---|
| `00_项目模板` | 每次新开一个视频项目，直接复制这一套 |
| `01_全局说明` | 总工作台怎么用，放什么，不放什么 |
| `02_全局素材库` | 通用封面样式、常用字幕样式、固定发布模板 |
| `03_账号定位` | 宝宝AI 的账号定位、人设、内容原则 |
| `10_视频项目` | 所有具体项目都放这里 |

## 单个项目结构

| 路径 | 用途 |
|---|---|
| `01_项目说明` | 这条视频讲什么，讲给谁听 |
| `02_原始素材` | 录屏、截图、参考链接、草图 |
| `03_脚本与标题` | 逐字稿、标题、封面字 |
| `04_项目演示素材` | 项目结果页、局部特写、运行产物 |
| `05_封面与截图` | 封面图、首图、平台截图 |
| `06_发布文案` | 小红书、抖音文案和评论区引导 |
| `07_导出成片` | 最终导出视频 |
| `08_发布清单` | 发布前检查 |
| `09_复盘` | 数据、问题、下次怎么改 |

## 使用方法

| 步骤 | 动作 |
|---|---|
| 1 | 复制 `00_项目模板` |
| 2 | 改名成 `项目_你的项目名` |
| 3 | 先写 `01_项目说明/项目简介.md` |
| 4 | 再往里面丢素材、脚本、封面、文案 |
| 5 | 成片统一导出到 `07_导出成片` |

## 适合你的原因

| 好处 | 说明 |
|---|---|
| 不串项目 | 每个项目单独存放 |
| 能长期复用 | 以后任何视频项目都走同一套流程 |
| 适合宝宝AI | 每条内容都可以看成一个独立小项目 |
