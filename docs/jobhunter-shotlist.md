# `job-hunter` 单条视频镜头清单

## 最终时长

60 秒左右。

## 镜头顺序

| 时间 | 镜头 | 怎么录 |
|---|---|---|
| 0-8 秒 | 招聘官网长列表 | 快速往下翻，制造岗位很多很乱的感觉 |
| 8-14 秒 | 最终结果页首页 | 直接停在最像封面的那一屏 |
| 14-22 秒 | 高分岗位局部 | 放分数、城市、优先级这些最直观的信息 |
| 22-30 秒 | 结果页继续滚动 | 强化“不是一堆链接，是排好顺序” |
| 30-38 秒 | 流程图 | 停在三步流程图，别晃 |
| 38-48 秒 | 配置文件和运行命令 | 只截关键局部，不要全屏代码 |
| 48-56 秒 | 回到结果页 | 再停一次，让人记住最终效果 |
| 56-60 秒 | GitHub 仓库首页 | 给一个结尾落点 |

## 剪辑原则

| 项目 | 要求 |
|---|---|
| 节奏 | 每 4 到 8 秒切一次 |
| 字幕 | 一次只放一句，不要堆满 |
| 画面 | 先结果，后过程 |
| 背景音 | 轻一点，不要压过字幕 |
| 结尾 | 一定要留关注引导 |
