# /job-hunter

## 这是什么

一键从招聘官网爬取所有岗位，与你的简历智能匹配打分，生成带可点击投递链接的 PDF 手册。

## 如何使用

在 Codex、Claude Code、Cursor 或 Gemini CLI 这类工具里直接说：
- "帮我爬取这个内推链接的岗位" + 粘贴链接
- "帮我筛选适合我的岗位"
- "生成投递手册PDF"

工具会自动：
1. 爬取该网站全部岗位（含详情页JD）
2. 读取你的简历进行匹配打分
3. 生成可点击投递的手册到项目输出目录

## 项目位置

所有脚本和输出都在项目目录内

## 三步流程

```
爬取岗位 → 匹配打分 → 生成PDF
(crawler)   (matcher)   (report_generator)
```
