## 小红书文案

打开招聘官网，翻页面、点详情、看要求、回来对比——投个简历半小时起步。

我用 Python 写了个小工具，一条命令解决。

你只需要：
1. 一条招聘链接
2. 你的简历 PDF

运行一行命令，剩下的交给它自动做：
- 爬取所有岗位 + 每条 JD 详情
- AI 跟你的简历匹配打分
- 生成一份可以直接用的投递手册 PDF

项目已经在 GitHub 开源，MIT 协议，随便用。
